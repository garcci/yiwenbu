# 《七条规矩》第一季设定集：七个外地人在井下等了三天，等来的是一句“就来”和一根封井的木桩

## 〇、一页总览

**一句话卖点**：爷爷留下七条保命规矩，我查到最后才知道，每条规矩后面，都有一个没被记下名字的人。

**故事核**：1979年腊月，黑水湾村办小煤窑透水，七个四川来的副业工困在井下。第三天，大队会计沈怀山趴在老井口朝下喊了一句“等着，就来”，用绳子放下去一筐火柴、棉袄和干粮。第二天，村里封了井。名册上，那七个人被改成“结账离队”。二十年后，沈怀山死在那口井边。他孙子沈砚回村奔丧，发现井里的东西学会了村里人的声音，在跟活人“借东西”。借了，就是答应了“就来”；72小时内不亲自下去把东西拿回来，就替那七个人死在井下。

**六分真**：1990年代末的北方矿村、1998到1999年国家整顿关闭小煤窑、私窑越界挖进老空区引发透水、外地副业工没有户口没人追、失温的人会反常脱衣、冬天不冻的出水河段、公用电话、BP机、县志办修新县志。
**四分虚**：井里的“它”会模仿听过的声音、会借东西、到期会收人；看事簿会自己多出一行字。只有这一种超自然，规则写死，见第一节。

**季终**：沈砚和许绾把七个人的真名写回账上，交出1979年的原始名册报警；县矿山救护队顺着1979年那条封死的巷道，救出困在韩家窑里的二叔和刘小军。这一次，真的有人“下来”了。正月里起出遗骨，名册上七个人，井下抬上来八具。

## 二、七条规矩：写在1979年那本账的背面

沈怀山1981年把1979年的大队账本拆开重订，背面朝外，做成了看事簿。第一页的七条规矩是他对外说的“老辈传下来的规矩”，其实每一条都是这二十年里看着一个人死去才写下的。

| 条目 | 对应哪种借 | 第一次有人因此而死 |
|---|---|---|
| 一、下雪的夜里有人敲门借火，不开门，不应声 | 门外借物 | 1981年冬，过路货郎 |
| 二、夜里有人叫你名字，叫到第三声以后，不要应 | 叫名借物 | 1983年冬，外村媒婆 |
| 三、小卖部的电话半夜响，不接 | 电话里让人把东西送到井边 | 1993年冬，县电话局线务员（村里1992年才拉电话） |
| 四、河上漂来的、路上捡到的东西，不要拿 | 反向借 | 1988年秋，放羊的半大孩子 |
| 五、扎纸人不点眼睛 | 点了眼睛的纸人认得人，能替它上门借 | 1985年冬，周德厚的徒弟 |
| 六、存疑一栏不许空 | 没有法力，是沈怀山给自己定的纪律 | 无 |
| 七、（被撕掉） | 正面：账上少了七个人，名字在背面。背面：七个人的真名，以及前五条每一条“试”死的那个人的名字 | 季终揭开 |

关键：前五条死的都是外人。沈怀山看见了，没拦。他要弄清楚“它”到底怎么借，好保住村里人。这是爷爷最重的罪，也是第七页背面那份名单的意思。

- 35岁，乡派出所民警。每次死人都来，按程序记录，不信邪；大雪封路时来不了。季终带县里的人来。

### 1979年的七个人（四川副业队）
许清禾（19岁，女，记账员）、罗德全（45岁，队长）、罗小川（17岁，队长的儿子）、唐有福（38岁）、唐有禄（35岁，兄弟俩）、何明贵（29岁）、杨春生（24岁）。“它”会他们的声音，说四川话。

## 五、地点卡（主要场景4个，次要3个）

- **沈家老宅**：村中间，坐北朝南三间土坯房加东厢房，院墙一人高，木头院门朝南。堂屋停灵、搭灵棚，供桌上点长明灯。东厢房是爷爷的屋，一张炕、一个木箱（锁着看事簿），墙上挂着旱烟袋的钉子空着。窗户是木格子糊白纸。院里一口压水井（冻了）。
- **小卖部**：村口路边两间红砖房，门口挂黄底红字“公用电话”铁牌，屋里柜台、玻璃罐装的糖、货架、一台14寸黑白电视，墙上挂一部红色拨号电话。后屋是刘长贵住处，一盘炕。
- **老井和北坡**：村北路口一棵老榆树下，青石井沿，井口一米宽，井深约十五米，干的。井底朝北有一道塌出来的缝，侧身能钻进北坡老窑的巷道。巷道低矮，木头棚子大半塌了，最里面是1979年七个人待过的高处，地上有那筐东西的残骸。下井要靠绳子和木梯，下面有缺氧和塌方的真实危险，进去必须带矿灯、绳子、试气的火柴（火苗变弱就退）。
- **纸扎铺**：老周家临街的屋子，满屋白纸、彩纸、竹篾、糨糊桶，纸人纸马靠墙站着，全都没点眼睛。
- 次要：**韩家**（村东砖瓦大院，铁门，有电视天线和一台柴油发电机，停电时全村只有他家亮）；**韩家窑**（东沟，绞车房、矿车道、窑口，东三巷朝北延伸）；**黑水河不冻段**（村西，河面冻实了，只有老窑出水口下游一百米一直冒白气、不结冰，河灯从那里漂出来）。

## 七、分案大纲（30章，每章3500到4000字）

每章开头固定两样东西：看事簿新多出的一行（没有就写“簿子上没有新字”），和当前所有倒计时（例如“二叔：剩41小时”）。这是全书的招牌，短视频里做成屏幕角标。

### 案一：借火（第1到5章）——救下二叔
1. **砚速回**：沈砚收到电报，雪夜赶回，爷爷已经死了，死在干井边，手里攥着没点的白灯笼。钩子：东厢房里爷爷的烟袋锅不见了，墙上钉子空着。
2. **守灵**：守灵夜，门外有人敲门，是爷爷的声音：“砚儿，给爷借个火。”他差点应声，忍住了。天亮簿子上什么都没多。钩子：翻到簿子最后一页，有一行初七夜的记录，爷爷的笔迹，交付者写的是“沈怀山”。
3. **第八盏灯笼**：许绾进村，打听1979年。老周说灯笼扎了七盏，门口挂着八盏。夜里又敲门，二叔喝多了，在东厢房窗口应了一声，递出一盒火柴。钩子：第二天清早，簿子上多了一行，交付者“沈建业”。
4. **72小时**：二叔不信，骂沈砚神经病。错误嫌疑：沈砚怀疑是韩续派人装神弄鬼（韩家有发电机、有BP机，夜里有人在村里走动）。苏大夫给沈砚讲“失温的人会脱衣服”。到第60小时，二叔在烧得通红的炕上开始发抖。钩子：沈砚在井口往下照手电，井底那道缝里有一点火光，像有人在下面划了根火柴。
5. **就来**：出殡当夜，沈砚背着二叔下井钻进北坡巷道，用火柴试气，找到火柴盒，二叔自己伸手拿了回来，体温回升。巷道里还看见一筐烂成渣的东西和一盏1979年的矿灯，旁边是爷爷的烟袋锅，他顺手拿了。钩子：爬出井口已经快半夜，村口小卖部的电话在响。

### 案二：半夜电话（第6到10章）——刘长贵死
6. **爹，我冷**：出殡那天夜里，刘长贵接了电话，是儿子刘小军的声音：“爹，我在井下，冷，给我送件袄，扔老井里。”他披着羊皮袄出门。可刘小军那一刻正在韩家窑上夜班。钩子：许绾在小卖部外面听见电话里还有另一个声音，说的是四川话。
7. **借据**：簿子上多出刘长贵那一行。沈砚顺着电话线走了一里地，在第七根电线杆下找到断头，用万用表一测：线十四号就被雪压断了，那天夜里电话根本不可能响。刘长贵不信，也不肯说1979年的事。钩子：下井找袄，巷道里袄不见了，雪地上有一行胶鞋印通往东沟。
8. **调包**：线索指向马成。韩续找上刘长贵：交出1979年的工钱底单，就把袄还你。许绾查出这张底单为什么值钱。钩子：刘长贵趁夜去了韩家。
9. **热炕**：刘长贵拿回了袄，以为没事了。沈砚发现袄领子里缝的名字不对，可刘长贵已经不让他进门。最后12小时，他把炉子烧到最旺，还是冷。钩子：沈砚连夜去韩家窑找真袄，被马成拦在窑口。
10. **零点**：零点，刘长贵死在热炕上，衣服叠好放在炕角，苏大夫说是溺死的，肺里有煤渣和冷水。民警赵卫东记为意外。刘小军在灵前跪着，说那天夜里他在巷道里，听见有人学他说话。钩子：沈砚在爷爷的烟袋锅里倒出烟丝，烟荷包摸着比记忆里鼓。（只埋，不拆，第28章回收）

### 案三：纸人点睛（第11到15章）——救下许绾
11. **订货单**：有人在纸扎铺订一对纸人，留了一张照片，要“照着画，画上眼睛”。照片是沈砚。老周不肯点睛，第二天纸人的眼睛已经被点上了，是朱砂。钩子：照片背面写着沈家的地址，笔迹是韩续的会计的。
12. **认人**：老周讲第五条为什么存在：点了眼睛的纸人认得人，能替“它”上门。纸人从纸扎铺不见了。许绾第一次把姑姑的信拿给沈砚看一角。钩子：夜里有人敲苏大夫家的门，是沈砚的声音：“阿绾，借我条围巾，冷。”
13. **红围巾**：许绾知道沈砚在老宅守夜，可那是沈砚的声音，而且门缝里露出的确实是沈砚那件军大衣的袖子。她应了，递出围巾。钩子：簿子上多出“许绾 红围巾”，沈砚看到时，她已经倒计时18小时了。
14. **四川话**：下井去找，巷道比上次更深，木棚子塌了一段，路要重新挖。许绾在巷道墙上看见煤块刻的字：七个名字和“腊月初七 有人说就来”。她第一次看到姑姑的笔迹。钩子：塌方，沈砚的手被压住，矿灯灭了，黑暗里有人用四川话说：“莫慌，就来。”
15. **拿回来**：老周顶着胆子下来送灯，许绾在第70小时亲手拿回围巾。沈砚左手冻伤。上来后许绾第一次哭，把姑姑的信全给他看。钩子：信的最后一封写着：“沈会计说，过了腊八，一起回四川过年。”

### 案四：河灯（第16到20章）——马成死
16. **不冻的河**：小年（这时许绾的倒计时还剩一天），村西那段从来不结冰的河上漂下来一盏一盏灯。村里孩子要去捞，被沈砚喝住。钩子：马成趁没人，从灯里拿走了一块旧上海牌手表。
17. **走针**：手表背面刻着“许清禾 1978”。马成不知道，戴着它去韩家。簿子上多出一行，交付者写的是“它”，接收者“马成”（反向借，第一次出现）。钩子：许绾在韩续手腕旁边看见了姑姑的表。
18. **烧了就断**：沈砚拦住马成，告诉他要亲手送回井里。韩续告诉马成，他爹说过“烧了就断”。错误嫌疑：沈砚以为韩续想借刀杀人灭口，其实韩续自己也真信。钩子：马成在韩家窑锅炉房把表扔进了炉膛。
19. **出水口**：沈砚和许绾查河灯从哪来：老窑出水口，地下水温比河水高，所以这段河不冻。出水口的流量在变大，说明巷道里的水在涨，有东西在往里挖。钩子：簿子上马成那一行，字开始一点点变淡。
20. **桑塔纳**：廿六夜，马成死在熄了火的桑塔纳驾驶座上，车门锁着，衣服叠好放在副驾驶，车里没有一滴水，他是淹死的。韩续第一次害怕。钩子：韩续半夜来敲沈家的门，是他本人，说要做个交易。

### 案五：叫名（第21到25章）——老周死
21. **交易**：韩续要看事簿和第七页，换一个秘密：二叔一直知道东三巷挖到了北坡边上。二叔承认，叔侄翻脸。钩子：韩续说，七个人里少了一个，他爹当年数过，只有六个人的声音。
22. **六个声音**：沈砚和许绾去问瘫在炕上的韩老栓，他只说得出一个字：“八”。苏大夫开口说了一半，又闭嘴。钩子：许绾在姑姑的信里发现，副业队出发时是八个人。
23. **北坡夜路**：为了找第八个人的线索，沈砚夜里上北坡看老窑口。身后有人叫“砚儿”，是爷爷的声音，一声，两声，三声。钩子：第四声，是5岁时他自己的声音：“爷，我在这儿。”
24. **替**：沈砚张嘴要应，手已经伸进兜里摸东西。老周从后面一把捂住他的嘴，自己应了一声“哎，来了”，把烟荷包扔了出去。钩子：簿子上多出“周德厚 烟荷包”，老周笑着说，这一声他欠了二十年。
25. **拉绳子的人**：沈砚要背老周下井，可廿八那天韩家窑放炮挖穿了老空区，北坡巷道低处进水，烟荷包已经沉在水下。老周知道自己活不过除夕夜，坐在纸扎铺里，把1979年腊月初五到初八的事从头讲到尾。钩子：老周最后说：“你爷爷那天放下去的筐里，还有一样东西，是给许家姑娘的。”

### 案六：第七条（第26到30章）——除夕
26. **透水**：廿九清早，韩家窑东三巷透水，二叔和刘小军被困在巷道高处。县里的验收组被雪挡在半路，救护队最快也要明天。韩续第一个想到的是封窑口，和他爹当年一样。钩子：二叔用矿灯在井下打出信号，三长两短，和1979年那七个人敲管子的节奏一样。
27. **除夕夜**：除夕夜，全村每家都有人敲门，每家都听见了亲人的声音，小卖部的电话响个不停。沈砚和许绾挨家挨户敲锣喊“别应”。十点，老周死在一屋子没点眼睛的纸人中间，沈砚赶到时，他的衣服叠得整整齐齐。钩子：沈家老宅的门响了，门外是二叔的声音，二叔此刻应该被困在井下。
28. **第七页**：许绾拆开爷爷的烟荷包，夹层里是撕下来的第七页：正面是1979年的原始名册，七个名字后面写着“困于井下”，被划掉；背面是第七条规矩，和这二十年试死的五个外人的名字。还有一封给沈砚的信。苏大夫终于作证。钩子：信的最后一句：“砚儿，筐里那样东西，我一直没敢放下去。”
29. **销账**：子时，沈砚当着全村人的面，把七个名字一个一个写回账上；许绾补上姑姑和第八个人的真名（第八个人留到第二季）。赵卫东带县里的人赶到，韩续被抓。沈砚带救护队从老井下到北坡巷道，那是他走了四次的路，打通到东三巷。钩子：巷道里所有的声音同时停了，只剩二叔在远处喊“这儿”。
30. **八个人**：救出二叔和刘小军。正月里起出遗骨，名册七人，抬上来八具。村里没人再跟沈家说话，二叔也不认他。沈砚回县城前，把烟袋锅放回了东厢房墙上的钉子。尾声：许绾送他到村口，小卖部的电话响了一声，就一声。

## 十一、年代道具和出图规范

**画面风格：冷峻写实。**灰蓝的雪天，铅灰天空，冻土，生锈的机械，土坯墙，粗糙的90年代末北方。一个画面只放一个异常焦点。红色只给三样东西：朱砂、白灯笼映出的暖光、许绾的围巾。参考电影《暴雪将至》的色调。

**必须有**：程控红色拨号公用电话、BP机（只有韩续和马成）、大哥大（只有韩续）、14寸黑白电视、蜂窝煤炉、二八自行车、军大衣、劳保棉袄、搪瓷缸、铝饭盒、马灯和矿灯、“大前门”烟盒、木格糊纸窗、土路、红漆标语（“安全生产”）、白色桑塔纳（全村只有一辆）。
**禁止出现**：手机、羽绒服、冲锋衣、LED灯、塑钢窗、水泥大路、现代品牌标志、彩色塑料制品、口罩。
**1979年回忆戏**：另起一套。蓝灰中山装和棉袄、解放鞋、矿工藤帽、电石灯和早期矿灯、手写工分簿、二八自行车更旧。画面用偏黄的褪色调和1999年区分。

**出图规则**：
- 先写场景卡（地点、时间、天气、月相、在场人物、各自衣服状态、手里拿什么），再出图，图片不许临时加东西。
- 看事簿只拍书脊、纸边、朱砂、手，不拍能读的字。
- 不拍“它”。只拍门缝、井口、空巷道、叠好的衣服、响着的电话。
- 不拍遗体面部、不拍伤口。
- 停电后（十四以后）夜景只有煤油灯、蜡烛、手电、长明灯和韩家发电机的光。
- 夜景亮度按月相：十五、十六雪地很亮；廿八以后漆黑。

## 十二、写作规则（让人看完一集催下一集）

- **倒计时同时跑**：任何时刻至少有一个倒计时在跑，中段要有两个重叠（小年前后许绾和马成同时在倒计时，除夕前老周和井下被困的人同时在倒计时）。章首写明剩多少小时。
- **每章三件事**：一个新信息、一个判断被推翻、一个更近的危险。章尾停在钩子上，钩子类型轮换：抛问题、揭新信息、局势变坏、人物判断翻转、停在门口、读者知道而主角不知道。
- **规则先演示后使用**：每条规则先有前例，再用来救人或杀人（见第一节四条前例）。
- **错误嫌疑**：每个案子前半段给读者一个会信的错误解释（多半指向韩续），后半段推翻一半：人确实在作恶，但危险本身是真的。
- **它越来越近**：第一案在门外，第二案在电话里，第三案用你身边人的声音，第四案东西送到你手上，第五案用你自己的声音，第六案全村。
- **像真事**：第一人称，回忆口吻（“那年我十九岁”），年代细节具体到牌子和价钱，对话带冀北口音和四川话。
- **六分真四分虚**：每个超自然现象旁边都要有一个能查证的现实细节撑着（电话线断了但电话响，河不冻是因为地下水温，冻死的人会脱衣服）。
- **合规**：不写血腥、伤口、遗体特写；不宣扬迷信（书里有民警、有大夫、有调查）；真实地名只用“冀北”“唐山”“宜宾”这类大地名，村、县、窑全虚构；章末注明“本章由AI辅助创作，故事纯属虚构”。

## 十三、改编成短视频的规则

- 小说每章改一集竖屏，4到6分钟；每个案子再剪一条15分钟左右的横屏合集（B站、YouTube）。
- 开头5秒放本章簿子上新多出的那一行，加倒计时角标。
- 旁白用第一人称“我”，不逐字念小说，改成口述；关键对话用角色配音。
- 每集只用本章场景卡里的画面。
- 片头片尾标“AI生成”。
