### 三、 8到12个最有共鸣的民间禁忌/设定

这些设定必须严格遵循一个原则：**读者在童年一定听长辈讲过，且背后有一套细思极恐的“逻辑防护网”**。

    *   *共鸣机制*：打破人类听到熟悉呼唤本能回头的安全感，植入“恶灵通过声音测距与定魂”的恐惧。

    *   *故事嵌入*：大雪封山深夜，门外传来指甲轻刮木门的“借火”声。门缝不能开，也不能回应，只能隔门将一枚铜钱或火柴从高处气窗扔出。
    *   *共鸣机制*：北方严寒地区的集体生存经验。冬夜在外的不是快冻死的人，就是“借阳气暖身”的撞客，开门即吹灭肩头火。

### 四、 怎样保证“真的会死人”又不违规

在平台审核（番茄、短视频、喜马拉雅）的高压线下，**血肉模糊是下乘，规则与环境带来的“异化死法”才是顶级高级的恐怖。**

#### 1. 死亡手法的合规转换（不写血腥，写“违背常理的生理异常”）
*   **“干地溺毙”**：违规者死在温暖干燥的炕头上，无任何外伤，但法医/仵工检查发现其肺部充满深井寒水与湿苔藓。
*   **“极寒反向失温”**：死在零下二十度的雪地里，衣服却被撕得精光，面带极其安详、甚至幸福的微笑，指甲因抠抓冻土而反向崩裂。
*   **“重力逆转”**：早晨开门，发现受害人笔直地“站”在屋梁顶上，头顶紧贴椽木，双脚悬空但姿态如同在天花板上行走。
*   **“泥化/物化”**：受害人的血液没有红色，切开伤口流出的是黑水矿泥；或者人未死，但皮肤逐渐硬化成冰冷的青石。
*   *合规核心*：**零血腥、零内脏、零残肢，但死状呈现出不可名状的冰冷诡异感。**

#### 2. 谁会死？死者的阶梯配置
*   **绝不能只死路人甲！**
*   **首死（立威）**：第1-2集死“村中德高望重的长辈/守旧人”。打破主角的安全网，证明“旧经验不管用了”。
*   **次死（因贪婪破规）**：第5-8集死“主角身边熟悉且自私的平辈”（如贪财的矿工发小）。读者有心理预期，但死法超出想象，强化规则的冷酷无情。
*   **虐心之死（善意被践踏）**：中期死“善良但为了保护他人被迫违规的至亲”（如老实的小卖部大爷）。制造强烈的情感悲剧与绝望感，激起读者同仇敌忾。
*   **主角的代价**：主角虽然不死，但每一次平账都必须付出不可逆的物理代价（如一只眼丧失色彩辨识能力、右手神经坏死发冷、折损寿数白头）。

#### 3. 死亡节奏控制（以短剧15-20集或网文前50章为例）
*   **序章（1-3集）**：出殡见丧，突现死人，规则初显。死1人。
*   **推进期（4-8集）**：双线并行，一人因破规横死，一人在生死边缘被主角极限操作救下（张弛有度，给希望）。
*   **高潮期（9-14集）**：防线崩溃，规则连锁触发，小规模群体死亡危机（矿井封堵、全村停电）。
*   **终局（15-18集）**：核心配角牺牲，主角直面源头，以命相搏。

### 七、 必须先由作者拍板的5个核心问题

在动笔写正文或脚本前，请作者必须对以下5个问题做“单选题”，这决定了作品的商业定位与生死线：

1.  **关于“超自然”的底线判定**：
    你是否彻底同意**“绝不把核心恐怖解释为幻觉或全员人为”**？如果平台审查卡住，你是否接受用“古老地脉未知辐射/未被发现的远古生物群落”这类伪硬核科学作为避风港，而不是妥协为“精神病/吃错毒蘑菇”？
2.  **女主角“阿绾”的商业去留**：
    短视频平台非常依赖漂亮女主的“颜值吸睛”。你是坚持要一个能真人出镜的实体女主角（如方案一中又飒又带刺的90年代红衣机车女韩彩凤），还是要保留一个虚幻神秘、只出声音或侧影的画中灵阿绾？
3.  **作品的体量与孵化目标**：
    这部作品的首要母体是什么？
    *   **A选项**：以起点/番茄为目标的长篇网文（需要无限升级的规则体系，百万字大长篇）；
    *   **B选项**：以爱优腾/抖音短剧为目标的精品中篇（20-30万字，强情节，单季闭环，15-20集，高度适合短视频切片宣发）。
4.  **主角的终极结局基调**：
    你倾向于哪种宿命感？
    *   **爽感破局**：沈砚破解所有规则，掀翻煤窑，砸烂老井，带幸存者走出大山拥抱新世纪；
    *   **中式绝望/守门人**：沈砚发现恶源无法消灭，为了天下太平，他最终撕下自己的人皮填平账本，接替爷爷成为新世纪坐在雪夜老宅里等候下一任借命人的“无面账房”。
5.  **短视频出片的主要形式**：
    未来小说剪短视频，采用哪种工业流？
    *   **形式A（口播沉浸流）**：第一人称旁白配AI生成静帧/微动态画面（重文案和配乐，成本低，适合故事号）；
    *   **形式B（短剧电影流）**：AI生成连续角色动作与对白，按标准影视分镜剪辑（重视觉连续性，制作难度高，但爆发力强）。

## Codex 第1轮
我的判断：**以《七条规矩》为骨架，吸收“账”的主题，放弃两套世界观硬拼。**真正值得做大的，是“长辈教你保命的规矩，可能也替长辈藏着秘密”。

“六分真四分虚构”不宜机械分配到每案。六分真用于生活、人物反应和调查过程；四分虚构用于异常机制。**异常可以无法用现实科学解释，但必须有边界、有代价，不能临时改规则救主角。**

以下是候选方案与推荐骨架，还不是已经完成的全书设定集。

**1．现有素材：保留什么，砍掉什么**

值得保留：

- **1990年代末、冬季、返乡奔丧。**熟悉的家突然变得不安全，比连续进入陌生凶宅更有持续压力。
- **沈砚的汽修学徒身份。**他能辨认线路、车辙、机械故障，也会误判。职业必须参与解题。
- **《看事簿》四栏。**“亲眼看见”和“听别人说”分开，是这部小说最有辨识度的调查方法。
- **七条规矩与缺失的一条。**同时提供生存压力、推理线索和祖辈秘密。
- **“账”。**它能连接承诺、亏欠、冒名、隐瞒，但不能变成自动判善恶的天道法庭。

必须改：

**砍“写满存疑就能免灾”。**随便写几个疑问算不算？为什么不知道反而安全？它容易把恐怖变成填表。四栏应帮助主角避免错误判断，真正救命必须靠行动。

**砍“每案最后八成人祸”的固定配方。**人为因素可以解释谁把人推入危险，不能解释掉危险本身。

**重写1960年粮仓起源。**大历史、粮仓、无名少女、煤窑控制被压在一个源头上，既容易失焦，也把女性受害者工具化。建议改成一次完全虚构的矿站封闭事件，明确谁决策、谁隐瞒、谁获利。

**阿绾可以留下，千年身份砍掉。**把她改成当代普通人。千岁收账人知道太多，会削弱少年调查的必要性；古风美人讲述现代事件，也不利于以后直接从小说取材。

**2．三个主线方向**

**方案一：《七条规矩》——借出去的东西，会带走一个人。最推荐。**

**一句话卖点：**爷爷留下七条保命规矩，却没告诉我，每条规矩都是拿一个活人试出来的。

**主线：**爷爷死后，收藏的七件旧矿站遗物被人以“照遗嘱归还”为名送进不同住户。沈砚发现遗嘱被改过，必须追回遗物，同时查清祖父当年究竟救过谁、牺牲过谁。

**核心装置与倒计时：**遗物附近会出现模仿熟人的借物者。有人答应借物，《看事簿》便出现姓名、所借物和到期时间。它记录已经发生的危险，不预言随机未来。

四分虚构锁定为以下规则：

1. 异常由七件遗物携带；封存时沉寂，被带入日常使用后才会出现。
2. **实时应答、主动交物同时发生，才成立一次“借”。**听见声音、接起电话是接触危险，不直接判死。
3. 借物者只能模仿它听过的声音与话语，不会读心。
4. 借期固定七十二小时。取回交出的原物，并由原交付者亲手收回，才能结束；替代品无效。
5. 毁掉原物不撤销借约，反而失去追回它的办法；烧簿、离村同样无效。
6. 到期未取回，借物者便带走邀请者。死亡不可逆，不设置复活补丁。

“借火”实际交出火柴盒，“借件衣裳”交出棉衣。现实依据是人情社会中的借还、主客和认人关系；**这些超自然效力全部属于小说虚构。**

调查负责回答：它模仿的是谁，东西被带去了哪里，谁故意促成这次交付。不同案件的难题可以是误认、原物混淆、证人隐瞒、救援受阻，不必重复“寻找法器”。

**生命威胁：**首案让一名已经建立感情的配角到期死亡。主角找到他，也确认死亡，不能用“只是失踪”敷衍。

**季终反转：**爷爷并非单纯的守护者。他曾诱导外来者接触遗物，以确认危险边界；七条规矩保存了成果，却隐去了试错者姓名。韩家掌握的是删改版，误以为可以稳定操控。沈砚最终要公开祖父的责任，才能取得最后一名证人的合作。

优点是亲缘、调查、民俗与死亡机制可以共同推进；扩成长篇时，应更换地域和人际关系，别不断增加更高级的簿子。

**方案二：《年夜饭少一个人》——全家都记得你，只有你的位置被别人坐了。**

**一句话卖点：**母亲多摆了一副碗筷，说那是我哥哥的；可我从来没有哥哥。

**主线：**返乡青年发现，不同家庭都在接纳一个“原本就存在”的亲人。只有旧照片、借据和私人日记留下矛盾。他必须在自己的母亲彻底认定替代者之前，找出最早被改写的那段家庭经历。

**核心装置：**不设自动派任务的簿子，每户家庭就是一个逐渐失守的现场。

**虚构规则与倒计时：**替代者必须被同一住户连续三个夜晚认作家人，并获得餐位、床位、出入资格；每晚取得一项。它不能凭空创造过去，只能拼接别人说过的记忆。阻止方法是让认可它的人面对具体矛盾、撤回认可，并收回它获得的生活位置；旁人替他否认无效。

**生命威胁：**第三夜结束，原本人被排斥在所有家门之外，无法再被家人认出，并在次日日出前死亡。记录不会一起消失，现实善后仍然存在。

**季终反转：**主角并非替代者，但他童年的一次获救，正是家人认错了另一个孩子的结果。母亲坚持错误记忆，是害怕承认自己当年放弃了谁。

这一案情感最强，适合中长篇；风险是容易只剩认知游戏，必须持续展示身体危险与现实后果。

**方案三：《末班车不回头》——沿一条已经废弃的路线，把失踪者接回来。**

**一句话卖点：**父亲留下的末班车，每晚都会停在地图上没有的站。

**主线：**年轻司机接手父亲旧车，发现失踪者仍在等待一班未完成的车。每救回一人，就更接近父亲当年擅自改变路线的真相。

**核心装置：**七个旧站点、七夜期限；每夜只能完成一次往返。

**虚构规则：**只有原车、原路线能进入异常路段；车辆与燃油仍服从现实限制；乘客必须在与自己经历对应的站点上车，司机不能仅凭外貌认人；被误认而带上车的东西，会模仿上一位乘客。天亮前未返回现存公路，车上所有活人死亡。

**生命威胁：**抛锚、错站和救错对象都有不可逆后果，不靠车辆突然恢复正常脱险。

**季终反转：**父亲当年改道确实救了一车人，却故意漏接了一站；如今回来索取解释的，并不全是死者，也有当年的幸存者。

它最适合视觉化，但民俗亲缘的厚度弱于方案一，交通与空间设定的工作量也更大。

**3．十个容易代入的禁忌，怎样真正进入故事**

以下是我的编辑判断，不是经过数据验证的热度排名；也不能把地域性说法写成全国统一习俗。定稿时筛选使用，别全部塞成杀人机关。

| 素材 | 嵌入方式与代入点 |
|---|---|
| 夜里有人叫名，别立刻应 | 声音像母亲，主角必须先判断母亲实际位置；怕的是认错熟人 |
| 陌生人借火 | 极普通的人情请求，把危险放在“拒绝显得不近人情”的瞬间 |
| 守灵别独自离开 | 主角必须在照顾活人与守住现场之间选择 |
| 饭桌别多摆碗筷 | 用家庭成员都熟悉的餐位，呈现家里逐渐多出一个人 |
| 筷子别直插饭中 | 长辈纠正动作时，发现这双筷子并非家里所有 |
| 纸人不点眼 | 作坊收到一张要求照着画的脸，画像竟是尚活着的人 |
| 叫魂别一遍遍叫 | 每次回应都更接近熟人的声线，考验人物为何继续相信 |
| 河里来的灯别捞 | 灯上有失踪亲人的字，救人冲动与警告发生冲突 |
| 半夜电话别接 | 明知爷爷已死，仍听见只有他会使用的称呼 |
| 回家先确认门牌 | 熟悉的院门、门槛磨痕都对，却多了一间屋；日常空间失去可靠性 |

纸扎有现实民俗工艺基础，但“点眼会产生异常”应明确作为创作设定，不能冒充工艺事实。[民俗工艺资料](https://www.ihchina.cn/art/detail/id/14165.html)

**4．怎样写得真会死人，又控制呈现风险**

**靠救援失败的过程和死亡留下的后果建立可信度。**

第一卷建议三次关键死亡：前段一名讨喜配角，证实期限有效；中段一名掌握线索的成年人，源于有根据但错误的判断；后段一名重要人物，其结局兑现此前的选择。其间安排真正成功的救援，让读者相信行动有意义。

不要每破一条规矩就杀人，也别只杀坏人、陌生人和刚出场的人。主角应有永久代价，例如失去信任、行动受限、救援失败后被家属追责；无需机械规定“用一次能力折寿一年”。

死亡可写呼叫无人回应、急救未能奏效、留下无人领取的工资、下一顿饭少摆一双筷子。避开伤口与遗体特写，画面和声音也不能用持续惨叫、贴脸怪相补偿。

**必须说明平台边界：不血腥、注明虚构，并不等于必然通过。**抖音公约对过度惊吓的画面、文字和声音均有限制；番茄也设有内容安全规范。因此短视频可以从小说抽取调查、倒计时和人物选择，但声画强度必须另行审核，不能承诺强恐怖原样呈现仍能过审。[抖音公约](https://sf3-cdn-tos.douyinstatic.com/obj/ies-hotsoon-draft/douyin_agreement/b94d5a1e-c676-4e99-92b5-2d5e26d2568b.html?enter_from=user_agreement)、[番茄内容安全须知](https://fanqienovel.com/writer/zone/article/7231069121566212151/)

**5．推荐方案的人物关系**

- **沈砚，19岁，汽修学徒。**想查明祖父死亡与遗物外流的关系，也想证明祖父值得尊敬。秘密：童年亲历过一次异常应答，却一直被家人解释为高烧。他的成长是接受“我爱的人确实做过错事”。
- **许绾，23岁，纸扎作坊记账人，昵称阿绾。**想找失踪父亲。她保存着父亲与沈怀山往来的旧单据，却暂不交出，因为其中也有父亲替韩家办事的证据。她擅长材料、尺寸和笔迹比对，不包办所有知识。
- **韩续，四十余岁，矿站旧业经营者。**想拿回证明父辈责任的遗物，利用禁忌恐吓住户。他只懂部分机制，并非操纵异常的法师；秘密是一次他以为成功的“转嫁”，其实尚未到期。
- **沈怀山，已故。**既救过人，也把别人置于危险。他保留四栏，是晚年的补救；删去姓名，则说明他始终没有完成坦白。
- **首案受害者，小卖部经营者。**想保护夜归的家人，因此借出棉衣。他不是愚蠢犯禁，而是面对可信伪装作出善意选择。家属此后参与追查，死亡持续影响主线。

核心勾连应是：**每个人都掌握另一人需要、却不愿公开的一段事实。**

**6．设定集怎样锁死时间与画面**

先写第一卷完整结局，再反推事件。建议建立以下六份表：

1. **世界规则表：**触发条件、范围、阶段、期限、解除办法、失败后果、例外是否存在；每条配一个成功例和失败例。
2. **双时间线：**当年真实经过，与人物口述版本并排；标明谎言何时被揭穿。
3. **逐日行程表：**日期、时段、天气、人物位置、同行者、交通耗时、随身物、借期余量。关键夜晚细到十五分钟。
4. **证据流转表：**物件编号、原主人、保管人、转交时间、损坏状态；另列每个人此刻知道什么。
5. **空间与年代表：**自绘村镇地图；锁定道路、院落、门窗朝向，以及电话、电力、车辆、取暖、医疗和报警条件。
6. **视觉连续表：**人物年龄、体形、发型、固定服装；道具尺寸、材质、磨损；每场景衣服是否湿、雪有多深、哪扇窗亮着。

尤其先修正日期：“农历1998年腊月”主要落在公历1999年春节前。可建议第一卷定于**1999年1月24日至2月6日，即腊月初八至廿一**，避免两套年份混写。[历法对照](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/1999.pdf)

保留这一年代，就不要把贴吧怀旧直接塞进人物生活；贴吧是2003年推出的。怀旧载体优先用磁带、旧杂志、录像厅和公用电话。[百度历史资料](https://www.baidu.com/search/postlzn.html)

出图必须从已定场景卡生成，提示词只引用人物、地点、道具编号及当天状态。**不能让图片临时决定小说里有什么。**

**7．必须先由作者拍板的五个问题**

1. 小说完整性与短视频适配发生冲突时，谁优先？
2. 是否接受重构已有六章，而不是继续补设定？
3. 三个方向选哪一个，第一卷准备写多长？
4. 是否允许爷爷承担实质责任，以及一名重要同伴永久死亡？
5. 是否保留1999年春节前，并让阿绾作为普通人进入同一年代？

我的选择是：**方案一，第一卷先写成六个相互牵连的案件，围绕追回七件遗物闭环；祖父的责任必须揭开，异常的全部来源可以留待后续。**
