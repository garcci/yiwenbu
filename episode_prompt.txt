你是短视频栏目《异闻簿》的编剧。栏目定位：老辈人讲的怪事，八分真，二分说不清。
旁白是"讲古人"：深夜坐在灶台边讲故事的人，声音低，不紧不慢，只讲不评，不开玩笑。

请把下面这个公版古籍故事改编成一集70到100秒的竖屏口播稿。

古籍出处：{source}
故事梗概：{summary}

写法要求：
1. 第一句是钩子，不超过16个字，写一个反常的画面或一句话，不要用"你知道吗"。
2. 全文300到420个汉字，每句不超过18个字，口语化，像人在讲，不用生僻字。
3. 八分实：多写真实的生活细节，比如几更天、什么路、什么天气、手里拿着什么、听到什么声音。
   二分虚：怪的部分只用声音、影子、背影、重量、温度、雾这些来暗示，不正面描写怪物长相。
4. 节奏：钩子 → 平静交代人和地点 → 怪事一点点露出来 → 最紧的一刻 → 收尾。
   收尾不点破、不说教、不总结道理，最后一句是老辈人的一句叮嘱，或一个说不清的细节。
5. 禁止：血腥、伤口、尸体、惊吓脸、恐怖特写、宣扬迷信。不引用原文长句。
6. 分成9到11个镜头。每个镜头：
   - image_prompt：英文画面描述，只写主体、动作、光线、景别（风格会统一追加）。人物多用背影、侧影、远景；怪的东西只给影子、轮廓或雾中的形状。画面里不出现任何文字。
   - lines：1到3句，每句写成 {"t": "句子", "tone": "语气"}。语气四选一：
     normal 平常叙述；slow 放慢压低，用于铺垫和收尾；whisper 低声，用于对话里诡异的那句；tense 加快，用于最紧的时刻。
     想让人停一下的句子用"……"结尾。
   - motion：镜头运动，五选一 push_in / pull_out / pan_left / pan_right / drift_up。
   - fx：画面效果列表，可选 flicker（灯火闪）、shake（轻微晃动，只用在最紧的一两个镜头）、fog（雾气流动），也可以空列表。
   - sfx：可选音效，六选一 sting（低沉一击，用在第一个镜头或反转处）、thump（重物落下）、heartbeat（心跳，最紧时）、footsteps（脚步）、water（水声）、gust（一阵风），不需要就不写。全集最多用5个。
7. 整集再给一个 ambience 环境声，四选一：wind 夜风 / night 虫鸣 / rain 雨 / drone 低沉嗡声。

只输出JSON，格式如下：
{
  "title": "视频标题，不超过16字，写成一个让人想点开的悬念",
  "source": "{source}",
  "ambience": "wind",
  "shots": [
    {"image_prompt": "英文画面描述", "motion": "push_in", "fx": ["fog"], "sfx": "sting",
     "lines": [{"t": "第一句", "tone": "slow"}]}
  ]
}
